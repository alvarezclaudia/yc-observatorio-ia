# Observatorio IA · YC

Análisis exploratorio de las descripciones públicas de empresas de Y Combinator. La clasificación está en validación; no mide la madurez de las operaciones internas ni constituye una clasificación oficial de YC.

## Datos

4.231 empresas de cohortes 2020–2026; 1.599 con etiquetas exactas AI o Artificial Intelligence. Corte: 1 de octubre de 2026. 2026 es parcial. Fuentes y reglas detalladas en la página.

## GitHub Pages

En Settings → Pages, seleccionar Deploy from a branch → main → / (root) y Save. La página se sirve desde index.html, con datos incluidos y sin instalación.
